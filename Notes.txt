===============================================================================
About strview
===============================================================================

* `strview_t` does not own the underlying memory. It provides read-only
operations such as searching, comparing, extracting substrings, and checking
prefixes and suffixes.

* Prefix and suffix removal operations do not modify the original string. They
only adjust the internal pointer and length so that the view references a
different region of the same memory.

* Trimming removes leading and trailing whitespace from the view. In most cases,
this can be done by adjusting the pointer and length without allocating
memory. If a function creates a separate trimmed copy, that operation requires
memory allocation.
